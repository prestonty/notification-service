# About

This microservice is intended to send multi-purpose notifications to the user.

It can send via email, text message, or even pop up in the tab/window.

It can send to many users or just one.

The purpose is to integrate into other applications.

It should also be capable of interactable notification

Applications:
- item is ready for pick up (E-commerce)
- An event was successful (Purchasing something, completing a form)
- Push notifications
- Daily or Monthly Reminders




## Go Commands

- `go run .` — Run project
- `go build` — Compile
- `go test ./...` — Run tests
- `go fmt ./...` — Format code
- `go mod tidy` — Clean up dependencies
